# PlayPuls 0.0.0.7

- **Feldwerte und Umrisse.** Die App kann frische Felddaten auch ohne Kartenmarker an die Website übertragen. Der echte Dedi-Wechsel zwischen Laichling und Catuaí wurde geprüft. Die Anzeige auf der Website hängt von der Freigabe des Kartenempfangs ab. Die automatische Übernahme eines Hintergrundbilds wird separat geprüft.
- **Serverübersicht.** Zeigt die aktuelle Spielerbelegung und Modanzahl. Für eindeutig zugeordnete Webinterfaces erscheinen nach dem Aktualisieren auch die bestätigten Updates samt Modnamen.
- **Modabgleich.** Lädt fehlende und geänderte ZIPs, pausiert während LS25 läuft und fragt bei Versionskonflikten nach. Der Upload der lokalen Version braucht eine separate Bestätigung. Fehlgeschlagene Übertragungen werden angezeigt.
- **Modupdates.** Bestätigte Updates lassen sich bei gestopptem Server installieren. ModHub-Angebote zählen separat. Vorhandene ZIPs lassen sich gezielt ersetzen, auch bei gleicher Version.
- **PlayPuls-Mod 0.0.0.6.** Liefert Feldwerte und Feldumrisse. Dieselbe Mod-ZIP ist im Setup enthalten und separat verfügbar. Auf Server und Mitspieler-PCs muss die passende Mod installiert sein.

Wer bereits **0.0.0.7** nutzt, installiert den korrigierten Build manuell. Der 1:1-Abgleich entfernt zusätzliche lokale Mod-ZIPs. Sichere eigene Änderungen vorher außerhalb des Modordners.
