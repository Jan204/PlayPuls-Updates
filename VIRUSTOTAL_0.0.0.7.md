# VirusTotal zu PlayPuls 0.0.0.7

[VirusTotal-Prüfbericht für PlayPuls 0.0.0.7 – Installer](https://www.virustotal.com/gui/file/193354c86e9e5958535181f5ded9bae611d81327a87e5842485935fb30c838e7) – 1 von 70 Engines meldet einen Verdacht.

[VirusTotal-Prüfbericht für PlayPuls 0.0.0.7 – Programmdatei](https://www.virustotal.com/gui/file/4ca5d047554f73b3e7ef0785d84a7f1f8f2e74a6f112310b5824eea1eff8a7e2) – 3 von 71 Engines melden einen Verdacht.

Beide Berichte gehören zum veröffentlichten Build vom 08.11.2026. Die gemeldeten Fundnamen entsprechen dem vorherigen Kandidaten. Eine Herstellerbestätigung als Fehlalarm liegt nicht vor. Microsoft meldet bei beiden Dateien keinen Fund. ClamAV meldete beim Installer einen Timeout. Avast-Mobile, BitDefenderFalx, Symantec Mobile Insight und Trustlook konnten den Dateityp nicht verarbeiten.

- Installer: Trapmine meldet `Suspicious.low.ml.score`.
- Programmdatei: Arctic Wolf meldet `Unsafe`, SecureAge `Malicious` und Skyhigh `BehavesLike.Win64.Backdoor.wc`.
